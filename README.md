# CodeAlpha Sentiment Analysis Project

## Project Overview
This project applies sentiment analysis to sample book reviews using VADER Sentiment and classifies the reviews as positive, negative, or neutral.

## Objectives
- Process sample review text.
- Calculate sentiment scores.
- Classify reviews by sentiment.
- Summarize the results.
- Visualize sentiment distributions and percentages.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- VADER Sentiment

## Files Included
- `sentiment_analysis.py` — Sentiment analysis source code.
- `sentiment_reviews.csv` — Input sample reviews.
- `sentiment_analysis_results.csv` — Classified results.
- `sentiment_distribution.png`
- `sentiment_percentages.png`
- `sentiment_summary.txt`
- Task 4 PDF report.

## How to Run
Install the required libraries:

`pip install pandas matplotlib vaderSentiment`

Run the script:

`python sentiment_analysis.py`

Ensure the input CSV file is available at the path specified in the script.

## Important Note
This project uses sample reviews for educational demonstration. The results should not be considered representative of real-world customer opinions.
